# Trilha ambiente

Coloque aqui o arquivo da música de fundo com o nome `ambient.mp3` (ou `ambient.m4a` / `ambient.wav`).
Sugestão: "Deus da Criação (Cover)" da Juventude Cross, exportado da gravação original.

- Formato: MP3 128 kbps (ou AAC/M4A). Um loop de 2 a 4 minutos é suficiente.
- Volume já é controlado pelo site (bem baixo, ~12%), não precisa reduzir no arquivo.
- Enquanto o arquivo não existir, o botão de som não aparece.
